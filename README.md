# PROBONO SMD — Legal Research & Analysis Portfolio

Target GitHub Pages:
https://probonosmd.github.io

## Struktur
- `index.html` — halaman utama
- `style.css` — desain
- `script.js` — menu mobile & filter project
- `projects/` — halaman detail project

## Deploy ke GitHub Pages
1. Buat repository publik bernama `probonosmd.github.io`.
2. Upload seluruh isi folder ini ke branch `main`.
3. GitHub → Settings → Pages.
4. Pilih **Deploy from a branch**.
5. Branch: `main`, folder: `/ (root)`.
6. Simpan dan tunggu proses deployment.
